# Changelog

## 1.0.0

First release of Hardlift: a flat, black-outlined marketplace look. Warm paper, pure ink and one loud pink carry the interface. Every control is a thin black rectangle with a small corner that lifts off the page on hover and leaves a hard offset shadow behind it. Nothing is blurred, soft or gradient. A dark theme comes with it.

- Hard-lift buttons and linked cards: hover moves the element up and left and shows a solid shadow, press returns it flush, and the effect switches to a plain color change under reduced motion.
- One pink action per screen state. Page-level actions stay ink or ghost, and pink goes only to the action the current state is about.
- Each section owns one flat, saturated header band. Text on any colored fill is ink, so contrast holds everywhere.
- Outline-on-demand pill tabs and chips: no border at rest, a black border on hover, filled when selected.
- Flat sticker illustration with a heavy ink outline. Placeholders and figures are always distinct objects drawn from basic shapes, and drifting shapes never cover text or controls.
- Tables reflow into stacked rows on phones with row actions always visible. Toasts sit in a corner and never cover the control that triggered them.
- Tables, toasts, dialogs, loading, empty and error states are derived from the same rules, and each has a verification step an agent runs before it is done.
