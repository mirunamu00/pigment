# Showcase starter

An empty React + Vite + React Router project. `pnpm harness showcase` copies it, hands an agent a published
system and one brief from `../briefs.json`, and lets it build the product from nothing — the way people use a
system on a new project. The agent lists the pages it built in `pigment.app.json`; those are captured.

Not a test: showcase runs are never scored, reviewed or used to change a template.
